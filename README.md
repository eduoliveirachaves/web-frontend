# 🛒 E-commerce - Programação para Web  

Este projeto é um sistema de **E-commerce** desenvolvido para a disciplina de **Programação para Web**.  
O objetivo é aplicar conceitos de **front-end e back-end**, explorando tecnologias modernas para criar uma aplicação funcional de compras online.  

## 🚀 Funcionalidades previstas (podem ser alteradas) 
- Cadastro e login de usuários  
- Listagem de produtos  
- Carrinho de compras  
- Finalização de pedidos  
- Área administrativa para gestão de produtos
